# Skinet

Skinet is an e-commerce web application designed to provide a complete online shopping experience, including product browsing, shopping cart management, user authentication, order processing, and product management.

## 🚀 Features

* User registration and authentication
* Product listing and product details
* Product categories
* Product search and filtering
* Shopping cart
* Order management
* Checkout workflow
* User account management
* Responsive UI
* Admin/product management functionality
* Database-driven product and order management

## 🛠️ Technologies Used

* **Backend:** ASP.NET / C#
* **Frontend:** HTML, CSS, JavaScript
* **UI:** Bootstrap
* **Database:** SQL Server
* **ORM:** Entity Framework
* **IDE:** Visual Studio
* **Version Control:** Git & GitHub

## ⚙️ Getting Started

### Prerequisites

Before running the project, make sure you have:

* Visual Studio
* .NET SDK compatible with the project
* SQL Server
* Git

### 1. Clone the repository

```bash
git clone https://github.com/Rajat08888/Skinet.git
```

Navigate to the project:

```bash
cd Skinet
```

### 2. Open the project

Open the solution file in Visual Studio:

```text
Skinet.sln
```

Update the database connection string according to your local SQL Server configuration.
